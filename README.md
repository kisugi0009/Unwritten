# Unwritten

> 一個陽春的線上作品倉庫，運行在瀏覽器裡，不需要帳號，不需要安裝。

🔗 **[立即使用](https://kisugi0009.github.io/Unwritten)**

---

## 功能

**作品管理**
- 建立多部作品，支援分類標籤、書脊顏色、封面圖片
- 可選擇分冊／分篇的層級結構

**章節撰寫**
- 每章獨立編輯，支援搜尋與排序
- 富文字編輯器：粗體、斜體、標題、對齊、清單、行距、分隔線

**人物設定**
- 固定欄位（年齡、性別、外貌、個性、背景故事等）
- 可自訂欄位，支援上傳人物照片

**故事大綱**
- 樹狀層級結構：卷 → 章 → 話
- 可折疊、批次刪除、匯出

**世界觀設定**
- 分類管理，每個分類有總覽編輯器與條目列表
- 條目支援富文字編輯

**靈感蒐集**
- 靈光一閃：隨手記錄靈感，支援自訂便條顏色
- 資料蒐集：存放你在網路上蒐集的各種資料，可上傳圖片或貼上網址，並以資料夾分類管理

**其他**
- 外部連結：儲存你連載平台、常用資料的網址
- 批次選取：靈感、資料、作品、大綱皆支援批次刪除與修改
- 匯入內容：支援 `.txt`、`.md`、`.docx`
- 匯出：TXT、Markdown、Word
- 雲端備份：Google Drive、Dropbox
- 佈景主題：四套預設主題＋自訂配色
- 字體設定：明體／黑體、大小、粗細

---

## 使用方式

直接開啟網頁即可使用，所有資料儲存在瀏覽器的 `localStorage`，不會上傳至任何伺服器。

建議定期使用右上角的**備份**功能，將資料匯出為 JSON 檔案保存。

---

## 雲端備份設定

進入設定頁面，即可連結 **Google Drive** 或 **Dropbox** 進行備份。

> 如果你想自行架設這個工具，需要在 `index.html` 頂部填入自己的 OAuth Client ID。詳細步驟請參考 [Google Cloud Console](https://console.cloud.google.com) 及 [Dropbox Developers](https://www.dropbox.com/developers/apps)。
